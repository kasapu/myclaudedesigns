# My Claude Designs

A collection of designs, UI components, and creative projects built with the help of [Claude](https://claude.ai).

## 📁 Structure

```
myclaudedesigns/
├── designs/        # Design files and assets
│   ├── ui/         # UI/UX designs and mockups
│   ├── graphics/   # Graphics and illustrations
│   └── templates/  # Reusable design templates
├── examples/       # Working code examples and demos
└── README.md
```

## 🚀 Getting Started

Browse the `designs/` folder to explore individual design projects. Each project includes:
- A description of the design
- Source files or code snippets
- Preview images where applicable

Feel free to open issues or pull requests to suggest improvements or add new designs.
